Each guide shows its own Gradle setup. The shape is always the same: import the BOM, declare artifacts without versions, and apply the Compiler Plugin if your style needs it.

## Target support

Most artifacts are published for every Kotlin target: `koin-core`, `koin-core-annotations`, `koin-annotations`, `koin-ktor` and `koin-test`. The others have gaps. Android uses the JVM variant of each artifact, and this table comes from the `build.gradle.kts` file of each module.

| Artifact | JVM / Android | iOS | macOS | tvOS | watchOS | Linux | Windows (mingw) | JS | wasmJs |
|----------|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| `koin-core-coroutines` | Yes | Yes | Yes | Yes | Yes | Yes | Yes | Yes | No |
| `koin-core-viewmodel` | Yes | Yes | Yes | Yes | No | No | No | Yes | Yes |
| `koin-compose`, `koin-compose-viewmodel`, `koin-compose-viewmodel-navigation`, `koin-compose-navigation3` | Yes | Yes | Yes | No | No | No | No | Yes | Yes |

Some artifacts and features are limited to one platform:

- **JVM only:** `koin-test-junit4`, `koin-test-junit5`, `koin-test-coroutines`, and [`verify()`](/docs/testing/verify/) in `koin-test`.
- **Android only:** `koin-android`, `koin-androidx-compose` and `koin-androidx-compose-navigation`. Use them for Android APIs such as `androidContext()` and the Android scope integrations.
- **Annotations on JS or wasmJs** require Kotlin 2.4.0 or later (Compiler Plugin README, KT-82395). The Compiler Plugin DSL works across the supported Kotlin range.

For every artifact, the BOM, and the current versions, see [Gradle artifacts](/docs/reference/artifacts/). [Kotlin Multiplatform install](/docs/platforms/kmp/install/) shows which source set each artifact goes in.
