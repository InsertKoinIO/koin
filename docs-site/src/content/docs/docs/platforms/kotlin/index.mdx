This page adds Koin to a plain Kotlin/JVM application (a console app, a desktop app or a backend that does not use Ktor) and starts the container from `main()`. For Android, Ktor and Kotlin Multiplatform, use the guide of your platform in [Pick your platform](/docs/get-started/pick-your-platform/).

## Prerequisites

- A Kotlin JVM project built with Gradle, on JDK 17 or later.
- Kotlin <Version of="kotlinMin" /> or later, which the Koin Compiler Plugin requires.

## Install

## Start Koin in main()

Declare your definitions in a module, then call `startKoin` once, at the top of `main()`:

<Tabs syncKey="koin-style">
<TabItem label="Compiler Plugin DSL">

```kotlin
import org.koin.core.context.startKoin
import org.koin.dsl.module
import org.koin.plugin.module.dsl.single

class Greeter
class App(private val greeter: Greeter)

val appModule = module {
    single<Greeter>()
    single<App>()
}

fun main() {
    startKoin {
        modules(appModule)
    }
}
```

</TabItem>
<TabItem label="Annotations">

```kotlin
import org.koin.core.annotation.ComponentScan
import org.koin.core.annotation.Configuration
import org.koin.core.annotation.KoinApplication
import org.koin.core.annotation.Module
import org.koin.core.annotation.Singleton
import org.koin.plugin.module.dsl.startKoin

@Singleton
class Greeter

@Singleton
class App(private val greeter: Greeter)

@Module
@ComponentScan
@Configuration
class AppModule

@KoinApplication
object MyApp

fun main() {
    startKoin<MyApp>()
}
```

`startKoin<MyApp>()` loads every `@Configuration` module, so you do not call `modules()`.

</TabItem>
<TabItem label="Constructor / Classic DSL">

```kotlin
import org.koin.core.context.startKoin
import org.koin.core.module.dsl.singleOf
import org.koin.dsl.module

class Greeter
class App(private val greeter: Greeter)

val appModule = module {
    singleOf(::Greeter)
    singleOf(::App)
}

fun main() {
    startKoin {
        modules(appModule)
    }
}
```

</TabItem>
</Tabs>

Then get an instance from the container. In `main()` there is no framework to inject into, so ask Koin for the entry point of your program:

```kotlin
import org.koin.mp.KoinPlatform

fun main() {
    startKoin { modules(appModule) }

    val app = KoinPlatform.getKoin().get<App>()
}
```

From there, everything is constructor injection. Classes that cannot receive their dependencies through a constructor implement `KoinComponent` (see [Injection](/docs/concepts/injection/)).

:::caution
Call `startKoin` once per process. A second call throws `KoinApplicationAlreadyStartedException`, also on iOS and wasmJs. To add modules after start, use `loadKoinModules`. Options, logging and properties are in [Starting Koin](/docs/concepts/starting-koin/).
:::
