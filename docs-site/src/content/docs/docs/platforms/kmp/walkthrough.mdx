## What you will do

You build an app that lists art objects from The Metropolitan Museum of Art, sharing Koin modules in `commonMain`, with platform definitions and injected ViewModels.

## Prerequisites

Android Studio, plus Xcode for iOS. It takes about 20 minutes.

## Get the code

The samples are in the [koin-getting-started](https://github.com/InsertKoinIO/koin-getting-started) repository:

- [`compose`](https://github.com/InsertKoinIO/koin-getting-started/tree/main/compose): Compiler Plugin DSL.
- [`compose-annotations`](https://github.com/InsertKoinIO/koin-getting-started/tree/main/compose-annotations): Annotations.

Clone the whole repository, because the samples read a version catalog from its root `gradle/` folder. Then open the folder for your style in Android Studio. The shared code is in the `composeApp` Gradle module, and the iOS app is in `iosApp`. The Annotations sample also has a `data` Gradle module.

:::note[What the samples cover]
Android and iOS only, using Navigation Compose. They have no tests and no Desktop or Web target. For those, see [Testing in commonTest](/docs/platforms/kmp/testing/) and [Start Koin once](/docs/platforms/kmp/start-koin/). The samples set their dependency versions directly and do not use the BOM.
:::

For the Annotations style, add `koin-annotations` too, and apply the Compiler Plugin in each Gradle module that declares definitions. In a multi-module project, expose `koin-annotations` with `api` from the `data` module, as the sample does.

## The application

The app fetches art objects from a remote API, caches them in memory, and shows them on a list screen and a detail screen:

```
MuseumApi -> MuseumStorage -> MuseumRepository -> ListViewModel / DetailViewModel -> Compose UI
```

It uses Ktor for HTTP, Kotlin Flow for data streams and Navigation Compose for routing. All the code here is in `commonMain` unless a comment says otherwise. Each block starts with its package, because the Annotations style scans by package.

{/* check: kmp-walkthrough-dsl, kmp-walkthrough-constructor */}

```kotlin
package com.jetbrains.kmpapp.data

import io.ktor.client.HttpClient
import io.ktor.client.call.body
import io.ktor.client.request.get
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.SupervisorJob
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.map
import kotlinx.coroutines.launch

interface MuseumApi {
    suspend fun getData(): List<MuseumObject>
}

class KtorMuseumApi(private val client: HttpClient) : MuseumApi {
    override suspend fun getData(): List<MuseumObject> = client.get(API_URL).body()

    private companion object {
        const val API_URL = "https://raw.githubusercontent.com/Kotlin/KMP-App-Template/main/list.json"
    }
}

interface MuseumStorage {
    suspend fun saveObjects(newObjects: List<MuseumObject>)
    fun getObjectById(objectId: Int): Flow<MuseumObject?>
    fun getObjects(): Flow<List<MuseumObject>>
}

class InMemoryMuseumStorage : MuseumStorage {
    private val storedObjects = MutableStateFlow(emptyList<MuseumObject>())

    override suspend fun saveObjects(newObjects: List<MuseumObject>) {
        storedObjects.value = newObjects
    }

    override fun getObjectById(objectId: Int): Flow<MuseumObject?> =
        storedObjects.map { objects -> objects.find { it.objectID == objectId } }

    override fun getObjects(): Flow<List<MuseumObject>> = storedObjects
}

class MuseumRepository(
    private val museumApi: MuseumApi,
    private val museumStorage: MuseumStorage,
) {
    private val scope = CoroutineScope(SupervisorJob())

    init {
        scope.launch { runCatching { refresh() } }
    }

    suspend fun refresh() {
        museumStorage.saveObjects(museumApi.getData())
    }

    fun getObjects(): Flow<List<MuseumObject>> = museumStorage.getObjects()

    fun getObjectById(objectId: Int): Flow<MuseumObject?> = museumStorage.getObjectById(objectId)
}
```

This is simplified from the sample. If the request fails, for example without a network, the list stays empty. A real app also shows the error and offers a retry.

`create(::buildClient)` lets Koin call a builder function for a class you do not own. `createdAtStart()` creates `MuseumRepository` when Koin starts, so the data fetch begins right away.

## Inject the ViewModels

Each screen gets its ViewModel with `koinViewModel()`, and the list screen gets `PlatformComponent` with `koinInject()`. The code is the same in every style:

{/* check: kmp-walkthrough-dsl, kmp-walkthrough-annotations, kmp-walkthrough-constructor */}

```kotlin
package com.jetbrains.kmpapp.screens

import androidx.compose.foundation.clickable
import androidx.compose.foundation.layout.Column
import androidx.compose.foundation.layout.fillMaxSize
import androidx.compose.foundation.layout.fillMaxWidth
import androidx.compose.foundation.layout.padding
import androidx.compose.foundation.layout.safeDrawingPadding
import androidx.compose.foundation.lazy.LazyColumn
import androidx.compose.foundation.lazy.items
import androidx.compose.material3.MaterialTheme
import androidx.compose.material3.Text
import androidx.compose.material3.TextButton
import androidx.compose.runtime.Composable
import androidx.compose.runtime.getValue
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import androidx.lifecycle.compose.collectAsStateWithLifecycle
import com.jetbrains.kmpapp.platform.PlatformComponent
import org.koin.compose.koinInject
import org.koin.compose.viewmodel.koinViewModel

@Composable
fun ListScreen(
    viewModel: ListViewModel = koinViewModel(),
    platform: PlatformComponent = koinInject(),
    navigateToDetails: (objectId: Int) -> Unit,
) {
    val objects by viewModel.objects.collectAsStateWithLifecycle()

    LazyColumn(Modifier.fillMaxSize().safeDrawingPadding()) {
        item {
            Text("Running on ${platform.getInfo()}", Modifier.padding(16.dp))
        }
        items(objects, key = { it.objectID }) { obj ->
            Text(
                text = obj.title,
                modifier = Modifier
                    .fillMaxWidth()
                    .clickable { navigateToDetails(obj.objectID) }
                    .padding(16.dp),
            )
        }
    }
}

@Composable
fun DetailScreen(
    objectId: Int,
    viewModel: DetailViewModel = koinViewModel(),
    navigateBack: () -> Unit,
) {
    val obj by viewModel.getObject(objectId).collectAsStateWithLifecycle(initialValue = null)

    Column(Modifier.fillMaxSize().safeDrawingPadding().padding(16.dp)) {
        TextButton(onClick = navigateBack) { Text("Back") }
        obj?.let {
            Text(it.title, style = MaterialTheme.typography.titleLarge)
            Text(it.artistDisplayName)
            Text(it.objectDate)
        }
    }
}
```

`AppNavigation` sets up navigation. Inside a `NavHost` destination, `koinViewModel()` ties the ViewModel to that navigation entry, so each screen keeps its own instance.

{/* check: kmp-walkthrough-dsl, kmp-walkthrough-annotations, kmp-walkthrough-constructor */}

```kotlin
package com.jetbrains.kmpapp

import androidx.compose.material3.Surface
import androidx.compose.runtime.Composable
import androidx.navigation.compose.NavHost
import androidx.navigation.compose.composable
import androidx.navigation.compose.rememberNavController
import androidx.navigation.toRoute
import com.jetbrains.kmpapp.screens.DetailScreen
import com.jetbrains.kmpapp.screens.ListScreen
import kotlinx.serialization.Serializable

@Serializable
object ListDestination

@Serializable
data class DetailDestination(val objectId: Int)

@Composable
fun AppNavigation() {
    Surface {
        val navController = rememberNavController()
        NavHost(navController = navController, startDestination = ListDestination) {
            composable<ListDestination> {
                ListScreen(navigateToDetails = { objectId ->
                    navController.navigate(DetailDestination(objectId))
                })
            }
            composable<DetailDestination> { backStackEntry ->
                DetailScreen(
                    objectId = backStackEntry.toRoute<DetailDestination>().objectId,
                    navigateBack = { navController.popBackStack() },
                )
            }
        }
    }
}
```
